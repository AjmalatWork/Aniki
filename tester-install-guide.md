# Installing Aniki (Beta) — Quick Guide

Hey! Thanks for helping test Aniki 🙏 This isn't a Play Store app yet, so installing it looks a
little different than usual — but it's easy, just follow along below. Takes about 2 minutes.

## 1. Open the invite email

You should have an email from **Firebase App Distribution** inviting you to test Aniki. Open it
and tap **"Get started"** (or the link in the email).

## 2. Sign in with your Google account

If it asks you to sign in, use the same Google account the invite was sent to. That's how Firebase
knows you're allowed to install the test build.

## 3. Install "Firebase App Tester" first

Before you can install Aniki itself, you'll be asked to install an app called **Firebase App
Tester** from the Play Store. This is normal — since Aniki isn't on the Play Store, Firebase App
Tester is just the little helper app that lets your phone download and install test builds like
this one directly. Install it like any normal Play Store app.

## 4. Go back and install Aniki

Once Firebase App Tester is installed, go back to the invite link/email and tap to install Aniki.

Your phone will probably show a warning like **"Install unknown apps"** or **"For your security,
your phone isn't allowed to install unknown apps from this source."** Don't worry — this is just
Android being cautious about anything installed outside the Play Store. Here's what to do:

- Tap **Settings** on that warning screen
- You'll see a toggle called something like **"Allow from this source"**
- Turn it **on** — specifically for the **Firebase App Tester** app (not any other app)
- Go back and the install will continue normally

That's it — Aniki will install like any other app.

## 5. Open it up

Once it's installed, just open Aniki from your app drawer like anything else. No extra setup.
